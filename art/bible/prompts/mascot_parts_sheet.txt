# TEMPLATE mascot_parts_sheet.txt: 2D Spine character parts (Bass Drop chr_gumbo / chr_croak,
# docs/games/bass-drop/ANIMATION_SET.md section 5). Lines starting with '#' are comments; the renderer drops them.
# Flow: approved design sheet (mascot_turnaround.txt#A) -> A rig master = the Spine setup pose (fixes view, facing
#       and scale) -> B body, C head/face, D hands, E wardrobe/props sheets -> key matte (--no-fit) -> cut each sheet
#       into pieces -> register every piece to the rig master -> hidden-area fill (symbol_parts_sheet.txt#C) -> Spine.
# Placeholders (render with --mascot <id> so IDENTITY_LOCK and KEY_HEX come from the bible; the rest from
# art/bible/artbible.json -> bassDrop.mascots.<id>, passed as --var by art/plan/build_plan.py):
#   {IDENTITY_LOCK}  mascots.rules.identityLock
#   {CHARACTER}      bassDrop.mascots.<id>.character (Bass Drop wardrobe, nothing held; overrides the Swamp Funk brief)
#   {FACING}         bassDrop.mascots.<id>.facing
#   {POSE_NOTE}      bassDrop.mascots.<id>.poseNote (A only)
#   {PART_LIST}      bassDrop.mascots.<id>.sheets.<body|face|hands|props> joined with ", " (B-E)
#   {STYLE_FORMULA}  artbible.styleFormula ; {KEY_HEX} mascots.<id>.keyHex (gumbo #FF00FF, croak #0000FF)
# 'near' = the side closer to the viewer in the three-quarter view (gumbo faces screen-right: near = his right;
# croak faces screen-left: near = his left). Spine _L/_R names are the character's own sides.
# Never use: kid, child, cute, chibi, baby.
# References: A = the approved design sheet; B-E = the approved rig master (view, scale) + the design sheet (identity).
# Output: A 2k (4:5 gumbo, 2:3 croak); B and C 4k 16:9 (pieces must reach the 2x authoring size, never upscaled);
# D and E 2k 3:2.
