## scores
- P1: technical art director (consistency, simulation-driven motion, human gates where AI is weak): Q9 A7.5 S7.5 — This proposal has the highest quality ceiling. It is the most complete on feel values, on human gates for mascot faces and acting, and on the art-bible and paintover strategy. Three weaknesses:
(a) It puts the workstation on Windows 11. CLI computer use is macOS-only and Chrome integration does not work under WSL, so it needs `cmd /c npx` in .mcp.json and loses headless EGL/Spine.sh simplicity.
(b) It uses Higgsfield/Kling/Seedance AI video for shipped cinematics. That output has no alpha, drifts off-model and has uncleared ToS.
(c) It routes 3D inserts through Spine sequence attachments, but spine-pixi-v8 4.3.13 lacks batching fix #3162.
Grafted into the final stack: human polish gates, the full juice ladder, EEVEE GPU toon look-dev, and the physics mapping.
- P2: maximum AI autonomy (T1 first, scripted, reproducible): Q8.5 A9.5 S8 — This proposal scores best overall and is the BASE of the final stack. Its strengths:
- a Linux headless workstation plus a self-hosted runner
- every production step is a committed script with a manifest row
- cinematics are rendered from the real mascot rigs, so they stay on-model and keep alpha
- Gemini is the default second judge and GPT-6 Astra is gated on OpenAI clearance
Its gaps: licence clearance is not enforced as a merge-blocking check, and it underplays human face/acting polish. Both are fixed by grafts from P3 and P1.
- P3: production safety (licence, provenance, budgets, no lock-in): Q7.5 A8.5 S9.5 — This proposal has the best governance:
- licence-audit as a required GitHub check
- allow and deny lists
- archived ToS versions
- cost logged per asset
- the Vertex GA model id
- Recraft outputs kept out of LoRA training
- the Rapier non-compat build
- a 2048 atlas cap with one {tps} folder per clip
Its quality ceiling is lower. It uses Cycles CPU as the reference renderer, keeps Houdini out, and allows AI video only after clearance. Grafted into the final stack: all of the governance, plus Cycles CPU as the CI/cloud fallback renderer.

## animationContract
A. SPINE SYMBOL SKELETONS (Spine 4.3 JSON)
Header: skeleton { spine:'4.3.xx', fps:30, referenceScale:100, images:'../../art/source/spine/' }.

Skeleton names:
- Royals: sym_10, sym_J, sym_Q, sym_K, sym_A.
- Themed high pays, ordered by pay: sym_h1 … sym_h4.
- Specials: sym_wild, sym_scatter, sym_bonus (only if it differs from the scatter).
- UI: ui_bigwin, ui_fs_intro, ui_fs_outro, ui_spin_btn.

File path chain: build/spine/<skel>.json → spine/<skel>.spine → public/assets/spine/<skel>.skel. Every symbol shares one atlas: symbols.atlas with symbols.png and symbols@0.5x.*.

Coordinates: author in Y-up. The runtime sets Skeleton.yDown, so in physicsTranslate +y means down.

Bones:
- root: at the cell centre.
- squash: at the cell's bottom-centre. It is the pivot for ALL squash and stretch.
- body: carries the art; the parts hang below it.
- ctrl_*: driven at runtime.
- ik_*: IK targets.
- phys_*: physics-driven. Each physics constraint has the same name as its bone.
- face_*: eyes, lids, mouth.
- fx_*: children of root, for glows and sparkles.

Slots are named after their main attachment. Attachment paths are '<skel>/<part>', for example sym_wild/body and sym_wild/body_blur. Additive blend is used only on fx_* slots.

Skins: default, plus gold, sticky and mystery.

Constraint array order: IK, then transform, then physics.

Physics constraint defaults:
- 3–4 Hz with ζ 0.2–0.3. Use strength = (2πf)²·mass and damping = exp(−2ζ·2πf/60). That gives strength 350–630 and damping 0.78–0.88; the default is 484 / 0.833.
- inertia 0.5–0.8, fps 60.
- limit, in skeleton units, must be at least the maximum fall speed. That is about 20000 if art is authored at 512 px and shown at 150 px.

Curves are always computed in code as absolute beziers: 4 numbers per channel, 8 for 2-channel timelines. Every weighted vertex needs at least one bone.

Budgets per symbol: ≤30 bones, ≤250 mesh vertices, ≤8 slots, no clipping.

B. SYMBOL ANIMATIONS (the validator enforces name, loop flag, frame window at 30 fps, required events and seams)
- idle: loop, 60–120 f. First key must equal last key. The runtime randomises trackTime so symbols never breathe in unison.
- land: once, 9–15 f.
  - land_impact event on the contact frame.
  - Squash to sy 0.83–0.87 with sx = 1/√sy; one rebound; ends on the setup pose.
- win: once, 18–30 f.
  - Anticipation dip, pop to ~125%, settle to 110%.
  - win_peak event.
  - Last frame must equal frame 0 of win_loop, so that mix is 0.
- win_loop: loop, 30–60 f.
- anticipation: loop, 12–24 f. Scatter, bonus and wild only.
- explode: once, 9–18 f.
  - explode_burst and explode_done events.
  - Ends at alpha 0.
- appear: once, 6–12 f. Cascade drop-in.
- blur: 1–2 f. Swaps region attachments to <part>_blur. No sequence attachments until spine-pixi-v8 ≥4.3.14 ships #3162.
- dim: overlay on track 1, or a Pixi tint. Never on track 0.
- Optional: reveal (mystery), expand (wild), sticky_lock, upgrade.
- Overlays: fx_glow on track 1 with entry.additive = true; blink on track 2.

Tracks: 0 = state, 1 = additive FX or dim, 2 = face/blink, 3 = look/talk.

Mixes: defaultMix 0.08; land→idle 0.15; idle→win 0.06; win→win_loop 0; any→explode 0.05; blur↔idle 0.

C. EVENTS
- Markers with no payload: land_impact, win_peak, explode_burst, explode_done.
- sfx: string payload = a cue id from audio/cues.yaml, for example land_high_03.
- vfx: string payload = an emitter id from the src/fx registry, for example fx_land_puff.
- shake: float payload = trauma to add, 0–1.
Validators must step 2 frames past the end, because events on the last frame fire on the next update.

D. RUNTIME BINDING (spine-pixi-v8 4.3.13)
- Construct with new Spine({skeleton, atlas, autoUpdate:false}) and call spine.update(gameDt) every frame.
- Spinning: setAnimation(0,'blur',true) and skeletonPhysics.setPositionInheritance(0,0).
- Reel stop:
  - setPositionInheritance(0,0.6);
  - skeleton.physicsTranslate(0,−impact·0.006);
  - setAnimation(0,'land',false), then addAnimation(0,'idle',true,0);
  - set entry.mixInterpolation = Interpolation.smooth.
- Win: 'win', then addAnimation 'win_loop'.
- Recycled or pooled symbol: setupPose(), then skeletonPhysics.resetTransform(), then updateWorldTransform(Physics.reset).
- Global physics tuning edits constraint.data.setupPose.* (the live pose is reset).
- Baked 3D turns and shatters are Pixi AnimatedSprites (<SYM>_<clip>_####) attached through spine.addSlotObject('fx_slot', sprite), so the squash bone still moves them.

E. BIG-WIN UI SKELETON (ui_bigwin)
- For each tier t in {big, mega, epic}: tier_<t>_in (once, title_hit event), tier_<t>_loop, tier_<t>_out.
- Slots txt_title and txt_amount hold runtime MSDF/BitmapText through addSlotObject. Text is never baked.
- vfx events (fx_coin_shower, fx_title_shine) fire the effects.

F. 3D MASCOTS (glTF animation names, sampled at 30 fps)
Files:
- Shipped: public/assets/mascots/mascot_<name>.glb.
- Source: art/source/3d/mascot_<name>/{mascot_<name>.blend, anim/<clip>.json, springbones.json}.

Clips:
- idle_loop: 4–6 s. Each mascot uses a different length (for example 4.8 s and 5.6 s) so they never sync.
- idle_fidget_01…03.
- Additive layers (AnimationUtils.makeClipAdditive): blink_add, breathe_add, look_add.
- anticipation_loop, react_reel_stop, react_near_miss.
- win_small, win_big_intro, win_big_loop, win_big_outro.
- bonus_trigger, freespins_idle, intro_drop.
Loops use matching first and last keys with THREE.LoopRepeat, because FModifierCycles is not exported to glTF.

Morph targets (≤15): blink_L, blink_R, squint, smile, frown, mouth_open, mouth_O, mouth_E, brow_up, brow_down.

Bones:
- Only Rigify DEF-* bones are exported.
- Spring chains are named spring_<part>_<n> and simulated at runtime by three-vrm-springbone. Wiggle is never baked onto them.
- Mesh names eye_L, eye_R and mouth_* are kept (optimize with --join false). Pupils use a UV-offset atlas.

Budgets: <15k triangles, 30–60 bones, 1–2 draw calls, 1024 px UASTC palette texture.

State machine inputs: reelStop(col), anticipationStart/End, winTier(small|big|mega|epic), bonusTrigger, fsStart/End.

Low-tier fallback: mascot_<name>_fallback.ktx2 containing idle_loop and win_small at 12 fps.

No child-like proportions (Stake rule).

G. RELATED ID CONVENTIONS
- Baked frames: <SYM>_<clip>_0001.png, with clip in {spin, turn, shatter}.
- FX ids: fx_<name>.
- Audio cue ids: <category>_<name>[_<nn>], for example reel_stop_1..7, land_{low,high,wild,scatter}, tumble_pop_1..8, anticipation_riser, win_{small,medium}, bigwin_{intro,loop,outro}, music_{base,fs}, stinger_fs_trigger, ui_*.
